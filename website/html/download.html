소스에서 빌드

정식 빌드 전에 개발 버전을 직접 빌드할 수 있습니다.

git clone https://github.com/sly22/kcode.git
cd kcode/vscode-main
npm ci
npm run watch
# 다른 터미널에서
./scripts/code.bat   # Windows
./scripts/code.sh    # macOS / Linux
